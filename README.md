# 回评 Agent 人工确认闸｜交互原型
面向电商评价处理场景的 AI 产品交互原型，展示回评草稿生成后，人工如何完成审阅、修改、驳回、异常处置与批量确认。

## 在线体验
[打开交互原型](https://yizhao-liu.github.io/review-confirm-gate/)

## 四个核心页面
- **确认队列**：按品牌、分流类别、置信度与状态筛选，选择待确认条目。
- **单条审阅**：核对原始评论与回评草稿，支持修改、二次确认和驳回。
- **异常处理**：演示低置信、不建议回复、售后复核及产品归属等异常处置。
- **批量确认**：核对批量条目，完成人工承诺后展示模拟结果与留痕。

## 演示边界
- 全部品牌、评论、人员与数据均为虚构。
- 页面中的草稿与回执为预置合成内容。
- 本项目为纯前端交互原型，不连接真实平台、数据库或账号系统，不产生真实发送。
- 本项目用于展示产品定义与交互设计，不代表生产系统上线成果或真实业务成效。
